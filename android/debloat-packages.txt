# Packages that debloat.sh removes from the tablet's user 0.
#
# "pm uninstall --user 0" hides a system app from the only user without touching /system, so
# nothing here can brick the tablet. restore.sh puts any of them back, and a factory reset
# restores all of them. One line per package; anything after # is a comment. Packages that
# aren't on your firmware are skipped.
#
# KEPT ON PURPOSE (do not add these):
#   com.google.android.gms, com.google.android.gsf, com.android.vending
#       Play services and the Play Store. Spotify, YouTube TV and the Home Assistant app need them.
#   com.google.android.webview, com.google.android.trichromelibrary
#       The WebView that renders the Home Assistant dashboard inside Counter Home.
#   com.android.chrome
#       The one browser left. Some app sign-ins open a browser tab for OAuth.
#   com.google.android.tts, com.google.android.marvin.talkback
#       Text to speech and accessibility.
#   com.sec.android.app.launcher
#       One UI Home. It is the fallback home screen if Counter Home is released as device owner.
#   com.samsung.android.honeyboard
#       Samsung Keyboard, the only keyboard left.
#   com.samsung.android.lool
#       Device care. Battery protection lives here.
#   com.sec.android.app.myfiles
#       My Files, handy for sideloading during maintenance.
